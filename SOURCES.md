Сетка 823 × 568 отсчётов сохранена без уменьшения разрешения. Вырезка прямоугольная, с небольшим контекстом вокруг города; вне границы поверхность обесцвечена. В браузере билинейная интерполяция используется только для высот векторных объектов. Значения raster сохраняются в Float32.

Снимок, указанный поставщиком: 2026-10-02T14:52:36 GMT.

Все waterway=river/stream/canal, пересекающие город, обрезаны по границе. Названия берутся из name:ru/name. Безымянные водотоки объединены в отдельную группу. Длины — сумма обрезанных сегментов в локальном равноугольном приближении, а не паспортная длина реки. Водные площади natural=water собраны из OSM multipolygons, включая отверстия, и обрезаны по той же границе. По уточнению пользователя Волга включена отдельным прибрежным участком вдоль города: её реальные ось и водный полигон сохранены между западной и восточной границами города, до 56.205° с.ш., за пределами сухопутной границы. Не следует трактовать полноту выгрузки как полноту реальной гидрографической сети.

## Пересборка

Python 3: rasterio, numpy, shapely, osmium.

```sh
python scripts/extract_osm.py /path/to/RU-CU.pbf /tmp/cheb-water.json
python scripts/prepare_data.py /path/to/DEM.tif /path/to/boundary.json /tmp/cheb-water.json
python -m http.server 8765 --bind 127.0.0.1 --directory dist
```

Исходные загрузки оставлены в `raw/` (не публикуются). Производные данные и GeoTIFF доступны в `dist/data/`.

## Визуализация и модель

Three.js r170, MIT, локально в dist/vendor. Собственная реализация, вдохновлённая https://sael.net/river-bend/.

Вертикальное преувеличение выбирается пользователем (1–30×). Ширина малых рек увеличена для видимости. Анимированные стрелки двигаются в направлении OSM ways с условной скоростью. Реальное течение в коллекторах, подпор водохранилища, расходы, батиметрия и грунты не моделируются.

Эксперимент: линии уплотняются до шага примерно 25 м. Поперечное отклонение точки от хорды её соседей задаёт знак и интенсивность смещения; смещение ограничено tanh, зависит от условного времени, течения и наносов и затухает на концах сегмента. Точки, выходящие из городской границы, сохраняют исходное положение; для отдельного прибрежного участка Волги ограничением служит охват карты. Поверхность DEM в эксперименте не меняется; отрыв меандров, перенос наносов и эрозия грунта не рассчитываются. Это качественная учебная иллюстрация, не модель Ikeda–Parker–Sawai и не прогноз.

Вертикальный масштаб меняется трансформацией общей 3D-группы, без пересборки геометрии. Маска поверхности выровнена с DEM и отмечает городскую территорию и водные площади.
