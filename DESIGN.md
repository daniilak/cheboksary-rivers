# Twenty Twelve 1.0 — оригинальная тема WordPress 2012 года

Дизайн сайта перенесён из настоящей темы **Twenty Twelve, версия 1.0**, WordPress team / Drew Strojny. Анонс темы опубликован 28 августа 2012 года.

- Официальный анонс: https://wordpress.com/blog/2012/08/28/new-theme-twenty-twelve/
- Страница темы: https://wordpress.org/themes/twentytwelve/
- Исходный архив версии 1.0: https://downloads.wordpress.org/theme/twentytwelve.1.0.zip

`dist/vendor/twentytwelve/style.css` — неизменённый оригинальный CSS. Его оформление применяется к статической разметке, воспроизводящей `header.php`, `page.php`, `sidebar.php`, `content.php` и `footer.php`: серый фон страницы, белый контейнер с тенью, Open Sans, название сайта, основная колонка карты и правая колонка виджетов. По запросу пользователя удалены меню, описание сайта, поясняющие публикации, подзаголовки, подсказки и подвал. Open Sans хранится локально; сетевые шрифтовые сервисы посетителю не нужны.

`dist/map-2012.css` содержит только интеграцию 3D-карты, элементов расчётной модели и диалога источников. PHP и WordPress-сервер не требуются для публикации на GitHub Pages.

Лицензия исходной темы — GPL v2 или новее; уведомление автора сохранено в CSS, текст лицензии лежит рядом. Шрифт распространяется по SIL Open Font License. `screenshot.png` — оригинальный снимок темы для сравнения.
