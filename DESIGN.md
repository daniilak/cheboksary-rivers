# Дизайн интерактивного атласа

Визуальные ориентиры, исследованные 7 октября 2026:

- [Twenty Twenty-Five](https://wordpress.org/themes/twentytwentyfive/): свободная редакционная композиция, выразительная типографика и гибкие блоки.
- [Blocksy Landscape](https://creativethemes.com/blocksy/starter-site/landscape/): природные цвета, чистая сетка и понятные призывы к действию.
- [Astra Starter Templates](https://wpastra.com/website-templates/): изучен каталог для сравнения структуры и навигации.

Это оригинальная статическая адаптация визуальных принципов, без установки WordPress и без копирования платного шаблона. GitHub Pages обслуживает HTML, CSS и JavaScript.

Тёплая бумага, тёмный хвойный цвет и терракотовый акцент. Georgia используется для заголовков и показателей, системный Arial — для управления. Внешние шрифты и изображения не требуются; основной визуальный материал — реальная 3D-карта проекта.

На широком экране — вертикальная панель исследования и большая карта. На телефоне — последовательное расположение пояснения, показателей, настроек и карты. Сценарии, источники данных и расчётные ограничения сохранены. Изменены только HTML-подписи и оформление; расчётное ядро не изменено.

Новый слой оформления: `dist/atlas.css`. Существующая публикация: `https://daniilak.github.io/cheboksary-rivers/`. Публикация из `dist` при push в `main` через существующий GitHub Actions workflow.
