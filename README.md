# Реки Чебоксар

Интерактивная 3D-карта на Copernicus DEM GLO-30: городские реки, прибрежный участок Волги, анимированные стрелки течения, изменение вертикального масштаба и условная модель размыва/отложения грунта на шкале 0–200 лет.

**Сайт:** https://daniilak.github.io/cheboksary-rivers/

## Локальный запуск

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

Откройте http://127.0.0.1:8765/.

Шкала годов видна постоянно. ▶ запускает годы; «До» показывает исходную поверхность; «Излучина» приближает участок. «Видео» создаёт 26-секундную запись модели; после завершения появляется ссылка скачивания.

Для записи прямо в локальную папку `../output` запустите `python3 scripts/preview.py` и откройте http://127.0.0.1:8766/?saveVideo=1.

## Проверка

```sh
node --check dist/app.js
node scripts/check-scene.mjs
```

## GitHub Pages

При push в `main` workflow `.github/workflows/pages.yml` проверяет сцену и публикует содержимое `dist`. Повторный запуск доступен через Actions → Deploy GitHub Pages → Run workflow.

Исходные загрузки из `raw/` не публикуются. Производные данные, GeoTIFF и библиотеки включены в сайт. Сборка и ключи API не нужны.
